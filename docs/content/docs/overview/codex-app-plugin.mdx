# Codex App Plugin

The plugin connects Codex to a local Canvas Agent so Codex can open oioi Canvas, read and create nodes, and start generation workflows. Source: `plugins/oioi-canvas/`.

## Install from this repository

```powershell
codex plugin marketplace add "$PWD"
codex plugin add oioi-canvas@oioi-canvas-local
```

macOS / Linux:

```bash
codex plugin marketplace add "$(pwd)"
codex plugin add oioi-canvas@oioi-canvas-local
```

The repo marketplace at `.agents/plugins/marketplace.json` already points to `./plugins/oioi-canvas`. Start a new Codex conversation after installation so the Skill and MCP tools load completely.

## Usage

In a new Codex conversation, say:

```text
打开无限画布
```

The plugin starts Canvas Agent, reads the connection URL and token, and opens `http://localhost:3100/?mode=new` to create and connect a canvas.

You can then ask Codex to summarize the current canvas, create prompts from selected nodes, or organize nodes into a generation workflow.

Reinstall or refresh the plugin after changing its manifest, MCP configuration, or Skills.

```bash
codex plugin remove oioi-canvas
```
