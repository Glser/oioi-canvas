# Codex App 插件

oioi Canvas 提供一个 Codex 插件，用来把 Codex 和本地 Canvas Agent 连起来。安装后直接说「打开无限画布」，Codex 会打开本机画布、读取节点、创建内容并触发生成。

插件源码在 `plugins/oioi-canvas/`。

## 本仓库安装

在仓库根目录执行：

```powershell
codex plugin marketplace add "$PWD"
codex plugin add oioi-canvas@oioi-canvas-local
```

macOS / Linux：

```bash
codex plugin marketplace add "$(pwd)"
codex plugin add oioi-canvas@oioi-canvas-local
```

仓库内的 `.agents/plugins/marketplace.json` 已指向 `./plugins/oioi-canvas`。安装后请新建一个 Codex 对话，让 skill 和 MCP 工具完整加载。

## 使用

新建 Codex 对话后直接说：

```text
打开无限画布
```

插件会启动本地 Canvas Agent，读取连接地址和 token，然后打开 `http://localhost:3100/?mode=new` 并自动新建、连接画布。

画布打开后可以继续说：

```text
读取当前画布并总结节点结构
根据选中节点创建一组生图提示词
把这些节点整理成一个生成流程
```

## 更新插件

改了下面这些内容后，才需要重新安装或刷新插件：

- `plugins/oioi-canvas/.codex-plugin/plugin.json`
- `plugins/oioi-canvas/.mcp.json`
- `plugins/oioi-canvas/skills/` 下的技能说明

重新安装后建议开启新对话，避免旧对话继续使用缓存中的技能和 MCP 工具。

移除插件：

```bash
codex plugin remove oioi-canvas
```
