# Local Development

The main application lives in `web/`. Flow connects directly to New API by default; standalone development can use manually configured model channels.

## Start the frontend

```bash
cd web
bun install
bun run dev
```

Open `http://localhost:3100`. For standalone development, set `VITE_NEW_API_ENABLED=false` in `web/.env.local`, restart Vite, then configure your endpoint and models in Settings. For Flow login integration, follow [New API Integration](/docs/development/newapi-integration); the production login Cookie is not assumed to work from plain HTTP localhost. Prompt sources and WebDAV are also accessed directly by the browser.

## Start the documentation site

```bash
cd docs
bun run dev
```

Common locations:

- Canvas, pages, and interactions: `web/`
- Prompt caching: `web/src/services/api/prompts.ts`
- Documentation content: `docs/content/docs/`
