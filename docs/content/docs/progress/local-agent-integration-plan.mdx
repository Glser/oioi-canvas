# 本地 Agent 架构与边界

当前源码方向已从「用户在原生 Agent 中对话、网页只提供工具」调整为「网页对话 + npm CLI 本地服务」。不新增 Electron / Tauri 客户端，也不实现自有 Agent 推理循环。

- **网页**：首页提交、对话、执行进展、问题与审批、停止操作；画布与素材继续使用浏览器本地存储。
- **本地 CLI**：自动发现已安装运行时，读取并安全投影原生模型、配置和能力，通过 Codex app-server 或 Claude Agent SDK 驱动本机 CLI，管理原生会话关联、转发事件与审批、保存提交回执，复用现有画布桥接。
- **原生 Agent**：负责推理、工具选择、原生历史、权限执行及技能；当前源码接入 Codex 和 Claude Code，其他运行时仍需逐个适配。
- **受管 MCP**：服务为会话注入工具并固定目标，不要求用户手动注册全局 MCP，不允许调用中切换网页或画布。
- **独立 MCP**：保留外部 Codex / Claude Code 主动操作网页的原有入口，但不作为首页需求的默认使用流程。

用户需要 Node.js 18.14 或更新版本、可用且已认证的 Codex 或 Claude Code，以及持续运行的连接 CLI。切换运行时会新建会话，历史记录保留各自运行时归属。当前仍为前台进程，不包含后台常驻、开机启动、远程机器或云端任务调度。

详细调用链、接口与存储边界见[连接原理](/docs/development/local-codex-canvas)。实现和验证状态见[待测试](/docs/progress/pending-test)；npm 0.8.0 已发布，使用协议 13 并支持 Codex 与 Claude Code 网页会话，升级后须停止旧连接器并重新启动。
